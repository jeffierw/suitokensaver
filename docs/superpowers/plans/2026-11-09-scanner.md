# Scanner Implementation Plan

> Execute inline with superpowers:executing-plans. No commits requested.

**Goal:** Ship a real read-only five-distribution Sui scanner.
**Architecture:** React/Vite frontend and Express API, shared validation, isolated
protocol adapters and GraphQL data access.
**Tech Stack:** JavaScript ESM, React, Vite, Express, official @mysten/sui, Lucide.
**Spec:** ../specs/2026-11-09-scanner-design.md

## Global Constraints

- No mock balances, private keys, wallet signatures, or broadcasts.
- Maximum 20 unique inputs; normalize names and deduplicate resolved addresses.
- Read complete pagination; report failures instead of empty success.
- Keep token amounts as decimal strings/BigInt, never floating-point arithmetic.
- Keep credentials server-side and preserve downloaded reference designs.

## Review Focus

- Invalid names, expired names, missing targets and alias collisions.
- Missing/malformed objects cannot become claimable or claimed.
- API errors and partial pagination cannot produce misleading zero totals.
- Old network responses cannot overwrite a newer scan.
- Long names/addresses and mobile controls must fit without horizontal overflow.
